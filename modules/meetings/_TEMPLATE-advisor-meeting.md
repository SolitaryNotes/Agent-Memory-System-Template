## 行动项

> **本表是原组会模板缺失的最高价值补充。** 组会结束时逐行确认：谁、做什么、什么时候。
> 没有行动项表的组会记录 = 一份没有下文的文档。

| # | 事项 | 负责人 | 期限 | 状态 | 对应来源 |
|---|---|---|---|---|---|
| 1 | {{ACTION}} | {{OWNER}} | {{YYYY-MM-DD}} | todo / doing / done | §{{X}} 导师建议 A{{N}} |
| 2 | {{ACTION}} | {{OWNER}} | {{YYYY-MM-DD}} | todo | §4 Q{{N}} |
| 3 | {{ACTION}} | {{OWNER}} | {{YYYY-MM-DD}} | todo | §6 Plan {{X}} |

**行动项字段约定**：

| 字段 | 规则 |
|---|---|
| 事项 | 动词开头，可判定完成与否（写"跑通 X 并得到 n=3 的 mean±std"，不写"研究 X"） |
| 负责人 | 具体到人；共同负责时写明主责 |
| 期限 | **必须有日期**；跨周任务写里程碑日期 |
| 状态 | `todo` / `doing` / `done` / `dropped`；下次组会前更新 |
| 对应来源 | 指回本文件的章节，保证「为什么有这件事」可追溯 |

**下周组会前自检**：

- [ ] 所有 `todo` 项已更新状态
- [ ] `dropped` 项已写明放弃原因
- [ ] 未完成项已在下周记录的 §1 上次回顾中说明
